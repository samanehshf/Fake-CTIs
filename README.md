**Fake-CTIs**
## False alarms, real damage: Adversarial attacks using LLM-based models on text-based cyber threat intelligence systems

This study investigates vulnerabilities across the entire CTI pipeline, focusing on how adversarial attacks such as evasion, flooding, and poisoning can disrupt system performance. It shows that adversarially generated fake cybersecurity text can significantly mislead ML and NLP-based classifiers, resulting in very high false-positive rates.
